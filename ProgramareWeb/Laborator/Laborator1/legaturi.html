Legaturi HTML (Sectiunea 5)

Se bazeaza pe folosirea de ancore cu elementul <a>. Exista doua tipuri de ancore:

  • Ancore sursa: au forma <a href="url">text</a> si reprezinta originea unei legaturi.
  • Ancore destinatie: au forma <a name="nume"></a> (sau folosind atributul id="nume") si reprezinta destinatia.

Capitolul 1: Concepte introductive HTML

HTML este limbajul universal utilizat pentru crearea si afisarea paginilor web. A fost dezvoltat initial pe baza SGML (Standard Generalized Markup Language) si foloseste etichete pentru a descrie structura continutului.

Capitolul 2: Marcaje de bloc vs. Marcaje incluse

Elementele de nivel bloc (P, H1-H6, TABLE, UL, OL) incep intotdeauna pe o linie noua si pot cuprinde alte elemente de bloc sau inline. Elementele incluse (B, I, U, A, IMG) se desfasoara in cadrul fluxului de text al paragrafului.

Capitolul 3: Hipertext si ancore (Definite cu ID)

In versiunile moderne de HTML, atributul id poate transforma orice element intr-o ancora destinatie, eliminand necesitatea marcajului <a name="...">.
