1. Formatare text si liste

Un document HTML contine date si marcaje. Marcajele pot fi de tip bloc sau incluse (inline).

Exemplu de liste imbricate:

  1. Limbaje de marcare:
    • SGML (Standard Generalized Markup Language)
    • HTML (HyperText Markup Language)
    • XML (Extensible Markup Language)
  2. Standarde si versiuni:
    • HTML 2.0 (1995)
    • HTML 3.2 (1997)
    • HTML 4.01 (1999)

Lista de definitii:

DTD
Document Type Definition - defineste tipul si regulile gramaticale ale unui document.
Element de nivel bloc
Element care incepe intotdeauna pe o linie noua (ex: H1, P, TABLE, FORM).
Element inclus (inline)
Element care nu incepe pe linie noua si ramane in fluxul textului (ex: B, I, A, IMG).
