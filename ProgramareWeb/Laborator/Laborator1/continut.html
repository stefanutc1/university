HTML (HyperText Markup Language) reprezinta „lingua franca” a World Wide Web-ului. A fost creat pentru a facilita partajarea documentelor stiintifice prin hipertext.

Evolutia versiunilor HTML:

  • HTML 2.0 (1995): primul standard oficial unificat.
  • HTML 3.2 (1997): adauga tabele, miniaplicatii Java (applets) si fuzionarea textului cu grafica.
  • HTML 4.0 / 4.01 (1997-1999): stiluri CSS, formulare avansate, internationalizare si cadre (frameset).
  • XHTML 1.0 (2000): reformularea HTML ca aplicatie XML cu reguli stricte de sintaxa.
  • HTML 5: aduce elemente semantice moderne, suport audio/video nativ si grafica interactiva (Canvas/SVG).
