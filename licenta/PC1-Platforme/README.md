## 1. Prezentare Generală

Acest director (`licenta/PC1-Platforme`) conține suita de platforme practice dezvoltate în primul an universitar în cadrul disciplinei **Programarea Calculatoarelor (PC)** la Facultatea de Economie și Administrarea Afacerilor (FEAA), Universitatea din Craiova.

Proiectele ilustrează conceptele de bază ale programării vizuale și orientate pe evenimente în mediul Microsoft .NET Framework utilizând **Windows Forms** și **Visual Basic .NET**:
* Controale grafice standard (TextBox, Label, Button, CheckBox, RadioButton, ComboBox).
* Validarea intrărilor utilizator și gestionarea fluxului de date.
* Structuri de control secvențiale, decizionale și repetitive.
* Manipularea evenimentelor grafice (`Click`, `TextChanged`, `SelectedIndexChanged`).

## 3. Cerințe & Compilare

* **Sistem de Operare:** Windows 10 / 11
* **Mediu de Dezvoltare:** Microsoft Visual Studio 2022 (sau 2019) cu workload-ul *.NET desktop development*.
* **Compilare:** Deschideți oricare dintre fișierele `.sln` din subdirectoare și apăsați `F5` pentru execuție cu depanare.
