# Portofoliu Universitar - Proiecte & Laboratoare

Repository centralizat ce conține proiectele academice, temele și lucrările de laborator dezvoltate pe parcursul anilor de studiu.

---

## Structura Proiectelor

| Director | Materie / Domeniu | Tehnologii & Limbaje | Descriere |
|---|---|---|---|
| [`PC1-Platforme`](./PC1-Platforme) | Platforme Computaționale (Anul I) | C#, .NET, Windows Forms, GDI+ | Suită completă de aplicații desktop GUI, formulare, fluxuri I/O și grafică |
| [`SD2-Teme`](./SD2-Teme) | Structuri de Date (Anul II) | C++, Algoritmică | Teme de laborator: vectori dinamici, matrici, pointeri, Divide et Impera, căutare binară |
| [`SD2-Proiect`](./SD2-Proiect) | Structuri de Date (Anul II) | C++, Liste & Arbori | Aplicație modulară pentru gestiunea structurilor de date cu persistență pe fișiere |
| [`POO2-Proiect`](./POO2-Proiect) | Programare Orientată pe Obiecte (Anul II) | C++, MFC, Visual Studio | Aplicație GUI MFC pentru gestiunea completă a vânzărilor și stocurilor |
| [`RC2-Proiect`](./RC2-Proiect) | Rețele de Calculatoare (Anul II) | Cisco Packet Tracer (`.pkt`, `.pkz`) | Topologie completă de rețea, rutare OSPF, VLAN-uri, DHCP și securitate |
| [`PS2-Practica`](./PS2-Practica) | Practică de Specialitate (Anul II) | Markdown | Jurnal zilnic de practică (11 mai - 29 mai) documentând etapele de dezvoltare software |
| [`BD2-Proiect`](./BD2-Proiect) | Baze de Date (Anul II) | MySQL, SQL, MySQL Workbench (`.mwb`) | Sistem de gestiune al activității academice: schemă relațională, proceduri, interogări |
| [`DAM3-Proiect`](./DAM3-Proiect) | Dezvoltarea Aplicațiilor Mobile (Anul III) | React Native, TypeScript, C#, F#, Docker, K8s | Platformă FinTech Monorepo cross-platform cu motor cantitativ și microservicii |
| [`LL3-LucrareLicenta`](./LL3-LucrareLicenta) | Lucrare de Licență (Anul III) | Markdown | Documentație de lucru și specificații arhitecturale pentru lucrarea de licență |

---

## Tehnologii & Limbaje Utilizate
* **Limbaje de Programare**: TypeScript, JavaScript, C#, F#, C++, SQL, x86 Assembly
* **Framework-uri & Biblioteci**: React Native, Expo, Next.js, Microsoft Foundation Classes (MFC), Windows Forms (.NET)
* **DevOps & Containerizare**: Docker, Docker Compose, Kubernetes, GitHub Actions CI/CD
* **Baze de Date**: MySQL, SQLite, IndexedDB
* **Networking & Simulare**: Cisco Packet Tracer
